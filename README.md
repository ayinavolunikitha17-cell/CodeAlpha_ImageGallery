# Image Gallery

## 📌 Project Overview

The Image Gallery is a web-based project created using **HTML, CSS, and JavaScript**.  
It allows users to view images in a clean and attractive gallery layout with interactive features.

This project demonstrates front-end web development skills including webpage structure, styling, and JavaScript functionality.

## 🚀 Features

- Responsive image gallery layout
- Attractive user interface
- Image preview functionality
- Easy navigation between images
- Smooth hover effects
- User-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS
- JavaScript

## ▶️ How to Run the Project

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in any web browser.

4. The image gallery will be displayed.
